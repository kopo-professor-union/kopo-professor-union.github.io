# 한국폴리텍대학지회 홈페이지

공개 주소: https://kopo-professor-union.github.io/

- 정적 화면: GitHub Pages (main 브랜치 루트)
- 로그인/게시글/첨부파일: Supabase
- 로그인: login.html / 관리자: admin.html
- 조합원 게시판과 기존 로그인 제한 글 99개, 백업 원본은 이 저장소에 포함하지 않습니다.
- backend-config.js에는 브라우저용 공개 publishable 키만 있습니다. 서비스 역할 키나 DB 비밀번호를 넣지 마세요.
- 본문은 일반 텍스트로 저장·출력합니다. 새 글과 첨부파일의 열람 권한은 데이터베이스/Storage RLS에서 검사합니다.
- 첨부파일은 비공개 union-files 버킷에 저장합니다. 개당 25MB, 한 번에 최대 10개 파일을 지원합니다.
- 새 계정은 pending 상태이며, 조합원 승인 후 전용 자료에 접근합니다. 관리자 지정은 DB 운영자가 별도 수행합니다.

## 초기 설정 중인 항목

최초 홈페이지 관리자 계정 생성·권한 지정 및 실제 글쓰기/업로드 종단 검증이 남아 있습니다. Supabase 기본 이메일 발송은 프로젝트 팀에 등록된 이메일로만 제한됩니다. 일반 조합원 가입을 운영하려면 별도 SMTP 설정이 필요합니다. 기존 정책 문서는 새 회원 운영 방식에 맞게 검토가 필요합니다.

SDK: Supabase JS 2.117.3 (MIT). vendor/LICENSE를 참고하세요.
